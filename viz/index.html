On-Demand Monitor — glass-box view

What you're looking at. Each row is one episode: the system's real reaction to some activity against a container (crash, restart, scan, or normal traffic), captured only from Docker-level signal. A cheap numeric gate ignores all-quiet episodes for free. Anything anomalous goes to a single Atlas vector search that retrieves similar past incidents from memory and, entirely server-side, computes how many were benign and how similar they are. If enough close neighbours are confidently benign, the episode is suppressed (no expensive LLM call); otherwise it is escalated to the LLM, whose verdict is written back to memory. A cheap-tier hard-signal override guarantees any real crash/OOM/scan is never suppressed, so attack recall stays 1.00 while the expensive-call rate falls as memory fills.
